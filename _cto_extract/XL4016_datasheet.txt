General Description 
The XL4016 is a 180 KHz fixed frequency 
PWM buck (step -down) DC/DC converter,  
capable of driving a 12A load with  high 
efficiency, low ripple and  excellent line and 
load regulation. Requiring a minimum 
number of external components, the 
regulator is simple to use and include 
internal frequency compensation and a 
fixed-frequency oscillator.  
 
The PWM control circuit is able to adjust the 
duty ratio linearly from 0  to 100%. An over 
current protect ion function  is built inside . 
When short protection function happens, the 
operation frequency will be reduced from 
180KHz to 48KHz. An internal compensation 
block is built in to minimize  external 
component count.

Typical System Application (TTL shutdown function) 
Logic level signals shutdown function can be used in typical system application with external 
components. When the TTL high voltage above 3.3V(referenced to ground, lower than 7V), 
the converter will shutdown, input current less than 5mA; when the TTL L ow voltage below 
0.8V(referenced to ground), the converter will turn on.
